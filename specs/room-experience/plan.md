# План

Сохранить FastAPI, Python 3.11, HTML/CSS/JS и один контейнер. Расписание и безопасные однозначные команды вычислять в коде. Организаторский API использовать как источник состояния, модель подключать для нечётких запросов. Разделить зачётный обработчик и жизненный цикл интерактивного заезда. Веб-клиент получает только состояние, расписание, результат команд и итоговые настройки.

Проверить протокол final на подменённом транспорте, обычный маршрут на живом dev-симуляторе и основные сценарии в Chromium с двумя размерами экрана.
