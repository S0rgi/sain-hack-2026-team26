## Локальный запуск первого прототипа

Нужны Python 3.11, доступ к API хакатона и выданный команде файл `api.token`. Значения токенов остаются вне репозитория.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
$env:HACK_API_URL = 'https://hack-api.be-healthy.tech'
uvicorn main:app --host 127.0.0.1 --port 8000
```

В другом окне PowerShell, с активированным окружением, задайте переменные и создайте dev-прогон. Путь к токену укажите из выданного набора.

```powershell
$env:HACK_API_URL = 'https://hack-api.be-healthy.tech'
$env:HACK_TEAM_TOKEN = (Get-Content -Raw '<путь к api.token>').Trim()
python dev_run.py
```

После обработки откройте `http://127.0.0.1:8000`. `dev_run.py` создаёт dev-прогон через `/runs`, передаёт его токен в локальный `/run` и выводит число обработанных записей. При повторном запуске создаётся новый прогон, к которому могут применяться ограничения организаторов.

Первый прототип распознаёт ограниченный набор формулировок для будильника, температуры, света, громкости и штор. Сценарий строится по профилю и простому поиску предпочтений в заметках. Обработка остальных намерений и произвольных формулировок, полная проверка правил сна и проверка на реальном симуляторе ещё необходимы. Экран использует сеанс заезда в виртуальное время заселения. Совместимость интерактивных действий с финальным прогоном пока не подтверждена.

Для проверок установите дополнительно `httpx` и выполните `python -m unittest -v test_case2 test_room_client`. Эти тесты используют имитацию API.



## Запуск через Docker

Нужны Docker Engine с Compose или Docker Desktop, а также доступ к API хакатона. Файл `api.token` должен находиться на компьютере вне репозитория. В Docker Desktop должен быть запущен Linux-контейнерный движок.

Из корня репозитория соберите и запустите приложение:

```bash
docker compose up -d --build
```

Откройте http://localhost:8000. Сначала экран ожидает заезд. Проверьте работоспособность сервера командой `docker compose ps` или откройте http://localhost:8000/health.

Чтобы загрузить dev-набор и подготовить номер, в Linux, macOS или WSL выполните:

```bash
export HACK_TEAM_TOKEN="$(tr -d '\r\n' < '/путь/к/api.token')"
docker compose exec -e HACK_TEAM_TOKEN app python dev_run.py
unset HACK_TEAM_TOKEN
```

В PowerShell используйте:

```powershell
$env:HACK_TEAM_TOKEN = (Get-Content -Raw '<путь к api.token>').Trim()
docker compose exec -e HACK_TEAM_TOKEN app python dev_run.py
Remove-Item Env:HACK_TEAM_TOKEN
```

Команда создаёт новый dev-прогон и обрабатывает его в работающем контейнере. После успешного ответа обновите страницу. Сценарий и состояние текущего заезда хранятся в памяти процесса. После перезапуска контейнера потребуется новый dev-прогон.

Адрес API по умолчанию — `https://hack-api.be-healthy.tech`. При необходимости задайте переменную `HACK_API_URL` перед запуском `docker compose up -d`. Для другого порта на компьютере задайте `APP_PORT`, например `APP_PORT=8080 docker compose up -d`, затем откройте http://localhost:8080. Контейнер привязан к localhost компьютера, на котором запущен Docker.

Для просмотра логов выполните `docker compose logs -f app`. Остановить приложение можно командой `docker compose down`. Нейросеть в текущем прототипе не подключена. Настройка Docker предназначена для локального запуска, стенд организаторов разворачивает бэкенд по своему контракту.
